## Product and runtime decisions

Margin has one Vietnamese learning mode. The reader offers summary and assessment actions, with a separate regenerate action for each current resource. Internal model settings, manual question counts, summary profiles and evidence switches are removed from the ordinary workflow. Existing artifacts remain compatible.

The runtime standard distinguishes anatomy, physiology, pathology, clinical reasoning, treatment/pharmacology, dental materials and prevention. It requires source terminology, directional relations, numbers, units, populations and exceptions. Original Vietnamese calibration cases cover weak versus useful summaries, reversed anatomical relations, condition-dependent indications, ambiguous clinical vignettes and useful option feedback. These examples teach construction; they are not medical facts to add to a different source.

Assessment planning precedes generation for the entire document. Each planned objective has a source-line anchor, concept, specific relationship and item family. A second family does not create another copy of the same objective. Every planned objective must have exactly one accepted question. Approximately three quarters of items use multiple-correct formats; this is the requested product choice, not an NBME or INBDE recommendation. Appropriate decisions receive single-best items. All formats use stable zero-based option identities and exact-set scoring. Display order changes only at an attempt boundary. Legacy letter-linked or explicitly ordered options retain order; new dependent or all/none shortcuts are rejected.

Summaries preserve the source's major lessons and subordinate headings. Transport segments share a lesson allocation and are assembled in order, without a final compression call. Vietnamese extraction joins adjacent accented font runs and normalizes Unicode; it does not guess missing letters. A normal transport segment targets 18,000 characters; unusually dense individual pages retain the previous 45,000-character safety ceiling. Smaller segments address observed output truncation without presenting processing segments as textbook chapters.

Source quotation and model review are complementary but fallible checks. A valid line ID proves the anchor exists, not that every generated claim follows from it. Answer audits examine selected and unselected options under the same stem conditions; summary audits check important omissions, altered conditions and unsupported claims. Invalid content is retried within bounded limits and is never published as a partial completed resource.

## Persistence and failure behavior

The authenticated account creates a Drive operation bound to its Google subject, PDF, checksum and resource kind. Drive's creation timestamp orders operations. Accepted artifacts are immutable; the current summary and current quiz are selected independently by operation order. A new accepted write precedes cleanup. A delayed older operation cannot remove or become the newer winner.

Explicit regeneration cleans only superseded artifacts of that PDF and kind, plus attempts belonging to the exact old quiz. It never deletes original PDFs, credentials, other accounts' data or reading progress. Reads of legacy history perform no migration-time deletion. Cleanup failures are deferred; idempotent retry can reconcile them. Current quiz identity is checked before and after attempt persistence. Browser responses are identity-bound so delayed attempt results do not attach to a replacement quiz.

Drive listing is eventually consistent. This is not an atomic database transaction or a global lock. A lost acknowledgement can mean the resource was stored; the UI asks the reader to reopen and check rather than falsely promising rollback. Once final save starts, cancellation is disabled. Hidden redundant records can remain after cleanup failures until reconciliation.

Rule 2026-11-27-vietnamese-3 adds durable model-response checkpoints: one newly completed response per request, then replay and continuation at the next inference boundary. Records are signed and bound to account, operation/source/input identity and request hash; evidence is pinned per segment. Scoped provider-outage markers survive cold requests. Permanently rejected content advances a bounded inference round, preserving already accepted batch/segment maps. Regression tests exercise a rejected draft through review, repair, re-review and finalization; cached replay consumes no new model call. This is software and local replay evidence, not a completed authenticated Drive acceptance run.
